# 1級電気工事施工管理技士 二次試験 技術記述トレーニング

スマートフォンのブラウザで技術記述を練習する、依存ライブラリなしの静的Webアプリです。

## GitHub Pages への公開手順

1. GitHubで新しいリポジトリを作成します。
2. `index.html`、`style.css`、`app.js` をリポジトリ直下へアップロードします。
3. GitHubのリポジトリで **Settings → Pages** を開きます。
4. **Build and deployment** の Source を **Deploy from a branch** にします。
5. Branch を `main`、フォルダを `/(root)` にして Save します。
6. 数分後に表示される公開URLへスマートフォンからアクセスします。

## 機能
- 16テーマの記述問題
- 自由記述欄と文字数表示
- 解答例との重要キーワード照合
- 「理解できた／要復習」の自己評価
- ランダム出題
- 練習済み数、理解済み数、連続学習日数
- LocalStorageによる端末内の学習履歴保存
- ダークモード
- スマートフォン向けレスポンシブ表示

## 補足
問題文・解答例は `app.js` の `DATA` で編集できます。試験対策では、公式教材・最新の法令・出題基準と照合しながら表現を調整してください。
